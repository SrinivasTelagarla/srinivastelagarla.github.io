Gatiyantra

Locomotive performance analytics

Analyses post-run locomotive data to score crew and train performance. Tracks over-speed, braking quality and section-wise adherence, with an actionable report for every trip.

Web

FogPASS Web

Live trip analysis for railway fog safety

Live trip analysis for FogPASS, the GPS-based fog-safety system that alerts loco pilots to upcoming signals and landmarks in low visibility. The web app follows every running train in real time and analyses each trip.

Tablet

FogPASS Tablet App

Real-time GPS dashboard for loco pilots

Touch-based tablet application for FogPASS. Designed a live, real-time dashboard that plots the train’s GPS points along the route and shows upcoming signals, landmarks and speed, helping loco pilots run safely in low visibility. Built with Qt Quick (QML), PySide6 and Python.
